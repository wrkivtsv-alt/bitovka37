## [Аналитик] Разбор текущего (bytovki37.ru)

### Что работает (почему в Яндексе)

- Жёсткая геопривязка: «бытовки в Иваново», телефоны, адрес.
- Плотные коммерческие ключи в H1/меню/тексте.
- Большой прайс (размеры × отделка) — релевантность и время на сайте.
- Возраст домена/контента (с ~2016).

### Что плохо (почему «плохая визитка»)

- Табличная вёрстка 2010-х, нет нормального mobile UX.
- Hero нет: сразу шум, прайс, SEO-простыня.
- Нет доверия: мало фото процесса, отзывов, сроков, гарантий, схемы «как заказать».
- CTA размыт (телефон в шапке, но нет сценария заявки).
- Каталог как ссылки-меню без визуальных якорей продукта.
- Юзабилити прайса на телефоне почти нулевая.
- Юр./cookie/политика — слабо или отсутствуют (риск для рекламы).

### Тильда (bitovka37.com)

- Типовой набор блоков: cover → о компании → 3 преимущества → 3 услуги → галерея → форма.
- Мало контента, слабая продуктовая глубина, аренда ≠ продажа с верандой.
- Визуально «шаблон», не бренд.

## Цель нового сайта

**Одностраничная (и лёгкий каталог) визитка производителя** бытовок / домиков / веранд в Иваново и области:  
тот же SEO-скелет и коммерческая ясность, но **современный визуал, mobile-first, понятный путь к заявке**, без Тильды.

Метрика успеха v1: звонок / заявка с главной ≤ 2 тапа на mobile; сохранение позиций по гео+коммерции.

---

## Что добавить (сверх «как у них»)

1. **Hero с продуктом** — full-bleed фото реальной бытовки/веранды, бренд, 1 оффер, 1 CTA.
2. **Каталог-направления** — не таблица сразу: визуальные входы (бытовки, с верандой, дачные, бани, хозблоки…).
3. **Прайс 2.0** — фильтр размер/тип + компактные строки; полная матрица — аккордеон или PDF/отдельная страница.
4. **Как работаем** — 4 шага: заявка → замер/подбор → производство → доставка/монтаж.
5. **Доверие** — сроки, гарантия, свой цех, геокарта, 6–12 фото работ, 3–5 отзывов.
6. **Квиз/калькулятор lite** — тип → размер → утепление → «ориентир цены» + заявка (сильно для Яндекса/рекламы).
7. **Липкий mobile CTA** — позвонить / WhatsApp / заявка.
8. **Микроразметка** LocalBusiness + Product/Offer, ЧПУ, Яндекс.Бизнес.
9. **Юрблок** — политика, согласие на ПДн у формы.
10. **Скорость** — статическая витрина, WebP, lazy, Core Web Vitals.

Опционально v2: отдельные карточки моделей, блог под SEO, личный кабинет — не в v1.

## Информационная архитектура (модели)

```
Главная (/)
  ├─ Hero
  ├─ Направления (якоря → /catalog/#…)
  ├─ Хиты / с верандой
  ├─ Почему мы
  ├─ Как заказать
  ├─ Прайс (срез) + ссылка на полный
  ├─ Работы / отзывы
  ├─ Форма + контакты
  └─ Footer (SEO-ссылки, юр.)

/catalog          — сетка направлений
/catalog/[slug]   — категория + прайс-срез
/contacts         — карта, реквизиты (можно якорь на v1)
/privacy          — политика
```

v1 можно свести к **одной длинной главной + /privacy**; каталог — секции с якорями.

## Визуальное направление (зафиксировано в моделях)

**«Цех у леса»** — не шаблонный cream/terracotta и не фиолетовый SaaS.

- Фон: туманно-зелёный / уголь
- Акцент CTA: янтарно-сигнальный (стройка)
- Тип: Unbounded (бренд/заголовки) + Onest (текст)
- Якорь: крупные фото изделия и участка, не абстрактный градиент
